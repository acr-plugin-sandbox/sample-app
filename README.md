# sample-app

Synthetic sandbox repository for [agent-code-review](https://github.com/Brg92/agent-code-review).
It is not a real product: the code is original, it is not meant to build, and scenario
branches contain intentional defects. Scenario pull requests are never merged.

Android app with Jetpack Compose and two product flavors, `free` and `paid`.
It consumes `core-lib` (`com.example:core-lib`).

The `free` flavor shows an upgrade banner; the `paid` flavor does not.
